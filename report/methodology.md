# Методологический отчёт (черновик структуры)

Отчёт для жюри собирается из `docs/research_design.md` и таблиц `outputs/` после финального прогона
с `events.only_verified: true`. Ниже — структура с целевым объёмом и источником каждой части.

| Раздел | Объём | Источник |

| 2. Данные и их особенности (24 месяца, одноимённые МО, нет региона) | 1 стр. | дизайн §2, `data_passport.json` |
| 3. Информационное множество: что модель знает в момент прогноза | 0,5 стр. | дизайн §3 |
| 4. Прогнозные модели и почему панель выигрывает у отдельного ряда | 2 стр. | дизайн §4, `forecast_metrics*.csv`, рис. 2 |
| 5. Модели-основы: zero-shot на уровне и на отклонении от общего фактора | 1 стр. | `forecast_metrics.csv` |
| 6. Новости: источники, разметка, согласование, абляции, плацебо | 2 стр. | дизайн §5 |
| 7. Детекторы сдвигов: преобразование, сравнение, полусинтетическая проверка | 2 стр. | дизайн §6, `changepoint_*.csv`, рис. 3 |

| 10. Как воспроизвести | 0,5 стр. | README |
